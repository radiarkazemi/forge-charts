# Order Blocks MTF

Bullish / bearish **Order Blocks** on chart TF + optional higher TFs.

Each block uses **N candles**; the rectangle is a **tight square** over those candles’ **HH → LL** — **not extended** to the right.

## MT5

1. Download `Order_Blocks_MTF.mq5`
2. MetaEditor → **Compile**
3. Attach to chart
4. Remove old indicator first if you already had v1.00

### Defaults
- Candles in block: `1` or `2`
- Chart TF on + TF1 `H1`
