# Session Daylight Box

Compact **trader-style corner HUD** for sessions & day open/close.

Still small — no big chart bands. Does not trade or draw over price.

## Panel shows
- Green **LIVE** / muted **IDLE** status
- Active session with color accent (Asia / London / New York / overlap)
- Local clock
- Session window hours
- Progress meter through the session
- Day open / day close
- Optional **Compact mode** for a tighter strip

## Style notes
- Accent border + session color change with the active window
- Progress bar fills as the session advances
- Corner placement: bottom/top × left/right
